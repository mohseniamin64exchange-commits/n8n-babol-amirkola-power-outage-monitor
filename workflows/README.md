# فایل Workflow

فایل خروجی کامل n8n باید با نام زیر در این پوشه قرار گیرد:

```text
babol-amirkola-power-outage.json
```

روش تهیه:

1. Workflow را در n8n باز کنید.
2. از منوی سه‌نقطه گزینه `Download` یا `Export` را بزنید.
3. فایل JSON را با نام بالا در این پوشه ذخیره کنید.

قبل از بارگذاری در GitHub بررسی کنید که توکن ربات، رمز، Cookie یا اطلاعات محرمانه داخل JSON نباشد. Credentialهای n8n معمولاً جداگانه نگهداری می‌شوند، اما بازبینی فایل ضروری است.
